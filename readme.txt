Thank you for choosing Savory & Sage! This is a premium, high-performance, and fully responsive landing page built specifically for fine-dining restaurants, cafes, and bars.

PROJECT STRUCTURE
The project is built with a clean and organized code structure:

index.html : Main website content and HTML5 structure.

style.css : Custom CSS3 styling, animations, and transitions.

script.js : JavaScript for the dynamic scroll-based navigation.

HOW TO SET UP THE PROJECT

Extract the downloaded .zip file.

Ensure all three files (index.html, style.css, script.js) remain in the same directory.

Open 'index.html' in your favorite web browser to preview.

To upload to a server, use an FTP client to transfer these files to your 'public_html' or root folder.

CUSTOMIZATION OPTIONS

[A] EDITING TEXT & LOGO:

Open 'index.html' in any code editor (VS Code, Notepad++, etc.).

Search for the "logo" class to change the brand name.

Scroll through the sections (Home, Menu, About, Contact) to edit the descriptions and dish names.

[B] UPDATING IMAGES:

Locate the img tags in 'index.html'.

Update the "src" attribute to point to your own image path.

Example: img src="assets/my-dish.jpg" alt="Dish Title"

[C] BRANDING & COLORS:

Open 'style.css'.

Find the ":root" selector at the top.

Modify the "--primary-color" variable to match your client's brand color.

PREMIUM FEATURES INCLUDED

Dynamic Header: Transparent at the top, turns solid white on scroll for better visibility.

Parallax Hero Section: Smooth background image depth effect.

Zero External Dependencies: Fast loading with no bulky frameworks.

Fully Responsive: Optimized for mobile and tablet users.
